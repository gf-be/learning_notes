## 已验证、不继续投入的路线

- 仅亮度增强：显著降低 scratch 指标。
- 含 scratch 图像的全图离线复制：会连带重复 chipping、splash、spot，无法真正控制类别均衡。
- scratch 直接粘贴与残差融合：合成样本未能超过在线增强，残差融合尤其明显退化。
- 单纯增加 imgsz 至 1536：当前配置下未优于 1280。
- 1280 的 lr0=2.5e-4：没有超过 lr0=2e-4 或 3e-4 的关键表现。
- 2048 的 AdamW lr0=1e-4：scratch mAP50-95 降至 0.156，不继续降低学习率。
- 当前 MuSGD 参数：scratch mAP50-95=0.150，不作为主方案；若继续研究优化器，必须先以 `args.yaml` 核实实际 lr0，并为 MuSGD 单独搜索学习率。

### P2：错误分析与部署阈值验证

使用 2048 AdamW 主候选，检查 scratch 的漏检、与 splash/背景纹理的混淆、边界偏移；根据 PR 曲线选择实际部署的置信度阈值。阈值调节可改变部署时的 Precision/Recall，但不会改变 mAP。

### P3：扩充真实数据，而非将现有图机械扩增到万级

- 优先增加不同批次、曝光、反光、工件位置与缺陷形态下的真实 scratch。
- 增加易与缺陷混淆的硬负样本，降低误检。
- 合成数据只能作为小比例辅助，必须始终在未增强真实测试集上验证。
- 可使用当前最佳模型筛选未标注图中的低置信度、漏检和误检样本，优先人工标注这些高价值样本。

### P4：可选算法改进

在 P1 的多随机种子结果确认 2048 的 scratch 定位优势后，再开展结构改进；第一优先级是面向小目标/细长缺陷的 P2 检测层。每次只改一个结构点，并固定 2048 AdamW 主配置作对照。

若业务明确要求缺陷轮廓，再进行分割复验：

```python
model = YOLO("yolo26m-seg.pt")
batch=2
mask_ratio=2
overlap_mask=False
```

重点对比 Mask mAP50-95、scratch 掩膜可视化和真实工件上的轮廓完整性，而不是只看检测框指标。
