# 2026-08-15 工作记录：数据重划分、YOLO26m 基准与物理增强准备

## 1. 本周目标

围绕楔形光学元件表面瑕疵检测任务，完成以下工作：

1. 重建可复现的数据集划分，并把正常（无瑕疵）图像纳入训练；
2. 在统一的 2048 输入尺寸下比较 YOLO26m 训练配置；
3. 排查验证集标签与缓存异常，保证指标可信；
4. 根据真实采集过程设计物理变化模拟增强，为后续扩充至约 3000 张训练图像做准备。

检测类别如下：

| 类别 ID | 类别名称 | 含义 |
|---:|---|---|
| 0 | chipping | 崩边 |
| 1 | scratch | 划痕 |
| 2 | splash | 麻点/点状缺陷 |
| 3 | spot | 污渍/斑点 |

> 研究对象为楔形滤光片/楔形光学件的三路显微合成图。实际检测中存在摆放位置变化、透射光不均、局部失焦、涂层反光等问题，因此后续增强必须尽量模拟这些真实物理变化。

### 2.3 与旧划分的区别

旧验证集为 133 张、850 个实例；新验证集为 200 张、1798 个实例。

- 旧验证集平均约 6.4 个实例/图；
- 新验证集平均约 9.0 个实例/图；

因此，新旧划分的指标不可直接作为“模型能力绝对高低”的结论。新划分上的指标更适合作为后续实验的统一、可信对照。

## 3. 验证集异常排查

曾出现一组无效训练：日志显示验证集为 200 张图，但仅识别到 7 张带标签图像、193 张背景图，验证实例数只有 63。

该现象与新划分的真实验证集统计（200 张、1798 个实例）矛盾，原因是服务器端标签文件或 `labels/val.cache` 缓存未正确同步。

处理措施：

1. 核对服务器 `data.yaml` 路径指向新数据集；
2. 删除验证集缓存后重新扫描；
3. 在训练/验证前检查预期图像数和实例数；
4. 将该次“200 图、63 实例”的训练标记为 **无效实验，不参与结果对比**。

后续有效训练均以日志中出现的 `200 images, 1798 instances` 为前提。

## 4. 有效基准训练结果

统一条件：YOLO26m、输入尺寸 2048、AdamW、同一新 7:3 数据划分、同一验证集（200 张/1798 实例）。

### 4.1 主要配置比较

| 实验 | batch | lr0 | 关键在线增强 | P | R | mAP50 | mAP50-95 |
|---|---:|---:|---|---:|---:|---:|---:|
| base5 | 2 | 0.0002 | Mosaic=0.10，轻量几何增强 | 0.480 | 0.388 | 0.350 | 0.175 |
| base6 | 6 | 0.0003 | Mosaic=0.10，轻量几何增强 | 0.526 | 0.386 | 0.336 | 0.168 |
| **base7** | **6** | **0.0006** | **Mosaic=0.10，轻量几何增强** | **0.515** | **0.397** | **0.361** | **0.184** |
| 高学习率试验 | 6 | 0.0010 | 轻量增强 | 0.426 | 0.307 | 0.284 | 0.149 |

说明：

- `base7` 在总体 P、R、mAP50、mAP50-95 上均优于 base5，因此选为当前正式基准；
- base6 的 Precision 略高，但总体 Recall 和两项 mAP 均低于 base7；
- `lr0=0.001` 明显不适合当前小规模数据与 batch=6 的组合，模型性能下降，尤其 scratch 几乎不能有效识别；
- 后续物理增强的第一轮实验应冻结 base7 的完整参数，只替换训练数据，避免同时改变多个变量。

### 4.2 当前正式基准：base7

训练设置：

```python
imgsz = 2048
batch = 6
optimizer = "AdamW"
lr0 = 0.0006
lrf = 0.02
cos_lr = True
warmup_epochs = 5
weight_decay = 0.0005

mosaic = 0.10
close_mosaic = 20
hsv_h = 0.0
hsv_s = 0.0
hsv_v = 0.02
degrees = 2.0
translate = 0.03
scale = 0.10
shear = 0.0
perspective = 0.0
fliplr = 0.5
flipud = 0.0
```

训练过程：191 / 300 epoch 触发早停；最优权重出现在第 71 epoch。

整体结果：

| Precision | Recall | mAP50 | mAP50-95 |
|---:|---:|---:|---:|
| 0.515 | 0.397 | 0.361 | 0.184 |

分类别结果：

| 类别 | P | R | mAP50 | mAP50-95 | 初步判断 |
|---|---:|---:|---:|---:|---|
| chipping | 0.591 | 0.428 | 0.428 | 0.239 | 可检出，但仍有较多漏检 |
| scratch | 0.466 | 0.129 | 0.109 | 0.0824 | 最主要短板，召回率严重不足 |
| splash | 0.496 | 0.547 | 0.472 | 0.192 | 召回相对较好，定位精度仍有限 |
| spot | 0.508 | 0.501 | 0.436 | 0.233 | 当前较稳定，但仍受背景/反光干扰 |

### 4.3 结论

1. 当前全局检测能力尚处于中等水平，不能通过继续堆叠 epoch 获得明显改进；
2. scratch 的稀少样本和低召回率是关键瓶颈；
3. 新划分后较旧划分指标低，主要源于验证集更大、缺陷更密集、训练图像相对减少，而非单纯模型退化；
4. 应以 base7 为标准基线，先验证高可信物理增强能否带来稳定收益。

## 5. 物理变化模拟增强准备

已准备可交互设置输出数量的离线增强脚本，覆盖以下真实采集变化：

| 增强方向 | 现实来源 | 标签处理 |
|---|---|---|
| 位置偏移与轻微尺度变化 | 工件摆放与成像位置变化 | 同步更新检测框 |
| 楔形局部失焦 | 楔形表面倾斜导致焦平面不一致 | 标签不变 |
| 透射光亮度/照明不均 | 透光观察与显微照明波动 | 标签不变 |
| 高光与反射变化 | 涂层反光、边缘高亮 | 标签不变 |
| 多因素组合 | 实际采集中的叠加扰动 | 视几何变化同步更新 |

相关脚本：

```text
scripts/augment_position_shift_interactive.py
scripts/augment_wedge_defocus_interactive.py
scripts/augment_transillumination_interactive.py
scripts/augment_reflection_interactive.py
scripts/augment_wedge_physical_combined_interactive.py
scripts/augment_wedge_all_physical_interactive.py
```

主脚本会：

- 询问输出目录、目标训练图像数量、随机种子等参数；
- 保留验证集不做离线增强；
- 保留原始训练图，生成增强图以扩充训练集；
- 记录每张增强图的方式和参数至 `augmentation_manifest.csv`；
- 记录总体配比至 `augmentation_summary.json`。

目标：将训练集从 465 张扩展至约 3000 张，验证集仍保持 200 张不变。

## 6. 下一步实验计划

### E1：物理模拟增强的严格对照实验

- 数据：原始训练集 + 物理增强图，目标约 3000 张；
- 验证集：固定为当前 200 张 / 1798 实例；
- 训练参数：完全复用 base7；
- 目的：测量物理模拟增强相对原始数据的独立收益。

### E2：空间增强去重实验（仅在 E1 后进行）

由于离线增强已包含位置变化，若 E1 无收益或下降，可保持其余参数不变，将：

```python
translate = 0.0
```

用于判断“离线位置变化 + 在线 translate=0.03”是否造成重复或过强增强。

### E3：scratch 漏检人工诊断

导出并逐张查看 scratch 的 FN/FP 样本，记录：

1. 是否为极细、低对比或局部失焦的真实划痕；
2. 是否受透射光、反光或边缘纹理干扰；
3. 标注是否过小、遗漏或类别定义不一致；
4. 是否被识别为其他类别或完全未预测。

诊断结论将决定下一步是补拍真实 scratch、定向增强 scratch，还是先修订标注规范。

## 7. 本周可复用结论

1. 训练前必须确认验证集图像数、标签数和实例数，避免缓存问题导致伪低指标；
2. 小数据集上不能仅依靠提高学习率提升性能，`lr0=0.001` 已验证会使效果明显下降；
3. 高分辨率 2048 对细小瑕疵仍有价值，但应搭配适中的 batch 和较低学习率；
4. 后续所有实验固定同一验证集、同一基线参数，并记录随机种子，才可以形成有效对比；
5. 数据增强的重点应是模拟真实成像物理过程，而不是随意叠加翻转、大角度旋转或不符合工况的图像变换。
