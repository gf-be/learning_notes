## 今日学习

- Git 仓库应优先记录可复现信息：脚本、配置、实验参数、指标、结论和失败原因。
- 原始数据、派生数据和模型权重通常不适合直接进入普通 Git 仓库；如果以后确需版本管理，可评估 Git LFS 或数据版本工具。
- 每日记录与阶段汇总用途不同：每日记录保留过程，阶段汇总提炼稳定结论。
