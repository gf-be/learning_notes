# 2026-07-31 训练记录：2048 高分辨率与优化器对比

 ## 实验目的

在固定数据划分、YOLO26m、`imgsz=2048`、`batch=2`、`mosaic=0.10` 的条件下，比较 AdamW 的不同学习率与 MuSGD 的当前表现。验证集固定为 133 张图像、850 个实例，其中 scratch 仅 20 个实例；其指标用于观察趋势，但不能只凭一次结果下最终结论。

## 统一训练设置

```python
imgsz=2048
batch=2
epochs=180
patience=100
hsv_v=0.02
degrees=2.0
translate=0.03
scale=0.10
fliplr=0.5
mosaic=0.10
close_mosaic=20
mixup=0.0
cutmix=0.0
copy_paste=0.0
seed=42
deterministic=True
```

## 结果分析

### 高分辨率的价值：改善 scratch 定位，不是全面提升

AdamW `lr0=2e-4` 将 scratch mAP50-95 提升至 `0.245`，是当前 scratch 严格定位的最佳记录，说明 2048 输入保留了细长、低对比 scratch 的空间细节。

但总体 mAP50-95 为 `0.252`，与 1280 路线接近；推理约 `19.3 ms/图`，明显慢于 1280 路线。因此 2048 应定位为 scratch 精细定位候选，而非所有类别上的绝对最佳方案。

### AdamW 的 1e-4 对 scratch 过于保守

从 `2e-4` 降至 `1e-4` 后，chipping、splash、spot 的严格定位略有提高，但 scratch mAP50-95 从 `0.245` 降至 `0.156`；最佳 epoch 也从 35 推迟到 75。当前数据、增强与训练周期下，`1e-4` 没有让 scratch 获得足够有效更新，因此 2048 AdamW 主学习率保留 `2e-4`。

### MuSGD 当前参数更偏向主类

MuSGD 当前结果中，chipping、splash、spot 的 mAP50-95 高于 AdamW `2e-4`，但 scratch mAP50-95 仅 `0.150`，总体 mAP50-95 也低于 AdamW `2e-4`。故当前结论是：MuSGD 在当前超参数下不如 AdamW，尤其没有改善项目最难的 scratch。

这不等同于 MuSGD 原理上无效。MuSGD 需独立调节学习率及其特有的 Muon/SGD 混合参数；直接沿用 AdamW 的学习率与调度，不能构成公平的优化器优劣结论。

## 优化器原理剖析

### AdamW

AdamW 为各参数维护梯度的一阶动量和二阶统计量，并按参数自身的梯度尺度自适应调整步长；权重衰减与梯度更新解耦。`batch=2` 时梯度噪声较大，且 scratch 样本少、细长、低对比，AdamW 的自适应缩放有助于在较小 `lr0=2e-4` 下稳定学习其定位细节。

### MuSGD

YOLO26 的 MuSGD 是 SGD 与 Muon 的混合优化器。它对二维线性权重和四维卷积核（重整形为二维后）采用 Muon 风格的正交化更新，同时保留 SGD 成分；设计目标是改善训练稳定性与收敛效率。[Ultralytics YOLO26 训练配方](https://docs.ultralytics.com/guides/yolo26-training-recipe/)

MuSGD 不等同于 AdamW 的逐参数二阶自适应缩放，因此同一个 `lr0` 在二者中没有可直接互换的数值含义；`muon_w`、`sgd_w`、`momentum`、`lrf` 会共同决定其有效更新。官方说明中，自动优化器会按迭代规模在 MuSGD 与 AdamW 之间选择，较长训练更倾向 MuSGD，较短训练更倾向 AdamW。[Ultralytics YOLO26 训练配方](https://docs.ultralytics.com/guides/yolo26-training-recipe/)

本项目训练集仅 532 张、batch=2、scratch 样本稀少；MuSGD 在大规模长迭代训练中可能呈现的优势，不一定会自然迁移到这一小数据场景。

### MuSGD 后续验证条件

只有需要专门研究优化器时，才继续 MuSGD 调参：

1. 先从 `args.yaml` 记录实际 `lr0`、`momentum`、`muon_w`、`sgd_w`；
2. 固定数据、模型、分辨率与增强；
3. 为 MuSGD 单独搜索学习率，不照搬 AdamW 的 `2e-4`；
4. 至少采用两个新随机种子复验；
5. 同时比较总体 mAP50-95、scratch Recall 与 scratch mAP50-95。
