## 2. 师兄改进模型参数核查

核查文件：

```text
yolo/args.yaml
yolo/train.py
```

师兄改进模型为 YOLO11n 多尺度边缘信息增强模型，原训练参数的主要内容为：

| 参数 | 原配置 |
|---|---:|
| epochs | 300 |
| patience | 100 |
| imgsz | 2048 |
| batch | 12 |
| optimizer | SGD |
| lr0 | 0.01 |
| lrf | 0.01 |
| momentum | 0.937 |
| seed | 0 |
| mosaic | 1.0 |
| close_mosaic | 0 |
| hsv_h / hsv_s / hsv_v | 0.015 / 0.7 / 0.4 |
| translate / scale | 0.1 / 0.5 |
| fliplr | 0.5 |

### 参数分析

- 师兄训练时使用的数据量较大，`batch=12`、`mosaic=1.0`、`scale=0.5` 和较强 HSV 增强更适合大数据训练场景。
- 当前项目数据量较小，直接沿用强增强可能造成工件反光、缺陷尺度和空间位置分布偏离真实图像。
- `args.yaml` 中虽然记录 `pretrained=true`，但当前 `train.py` 从模型 YAML 创建网络，`model.load(yolo11n.pt)` 处于注释状态；因此需要进一步确认该次训练是否实际加载了预训练权重。
- 后续如继续训练师兄模型，应先进行“预训练权重 + 轻量在线增强”的受控实验，避免同时改变过多变量。

建议候选方向：

```text
imgsz=2048
batch=8 或 12
mosaic=0.10
hsv_v=0.02
degrees=2～5
translate=0.03
scale=0.10
seed=42
deterministic=True
```

第一轮可保留 SGD，只降低学习率并减弱增强；第二轮再单独比较 AdamW，以区分增强策略和优化器带来的影响。

## 4. 总体指标对比

| 策略 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|
| 统一阈值 `conf=0.25` | 433 | 418 | 417 | 0.509 | **0.509** | 0.509 |
| 分类别阈值 | 415 | **358** | 435 | **0.537** | 0.488 | **0.511** |
| 变化 | -18 | -60 | +18 | +0.028 | -0.021 | +0.002 |

### 结果分析

- 分类别阈值减少 60 个 FP，Precision 提高约 2.8 个百分点。
- 同时减少 18 个 TP、增加 18 个 FN，Recall 下降约 2.1 个百分点。
- F1 仅从 0.509 提高到 0.511，综合收益很小。
- 该策略适合作为“减少误报”的部署候选，但不能视为模型能力突破。

| 类别 | 统一阈值 P | 统一阈值 R | 统一阈值 F1 | 分类别阈值 P | 分类别阈值 R | 分类别阈值 F1 |

### 类别变化

- `chipping`：阈值从 0.25 提高到 0.30，FP 减少 20 个，但 FN 增加 6 个。

- `splash`：阈值提高后 FP 减少 44 个，但 FN 增加 15 个。
- `spot`：阈值保持 0.25，因此结果完全不变；其 180 个 FN 和 156 个 FP 是当前最大的绝对错误来源。

## 6. 错误原因统计

分类别阈值方案共记录 793 条对象级错误，涉及 122 张验证图像：

```text
TP=415
FP=358
FN=435
存在 FN 的图像=103 张
存在 FP 的图像=99 张
同时存在 FN 和 FP 的图像=80 张
```

### FN 构成

| 自动诊断原因 | 数量 | 占 FN 比例 |
|---|---:|---:|
| 完全未检测到 | 348 | 80.0% |
| 定位偏差或置信度不足 | 57 | 13.1% |
| 类别混淆 | 30 | 6.9% |

### FP 构成

| 自动诊断原因 | 数量 | 占 FP 比例 |
|---|---:|---:|
| 背景、反光、边缘干扰或可能漏标 | 209 | 58.4% |
| 定位偏差或重复预测 | 101 | 28.2% |
| 类别混淆 | 48 | 13.4% |

说明：CSV 中的 `reason` 是根据预测框、类别和 IoU 自动生成的诊断假设，不等同于人工确认结论。特别是“反光、边缘干扰或漏标”必须查看导出的原图和标注后才能进一步细分。

### 各类别错误构成

| 类别 | 完全未检 FN | 定位 FN | 混淆 FN | 背景类 FP | 定位/重复 FP | 混淆 FP |
|---|---:|---:|---:|---:|---:|---:|
| chipping | 72 | 17 | 3 | 46 | 38 | 8 |
| scratch | 10 | 2 | 0 | 3 | 4 | 0 |
| splash | 129 | 13 | 9 | 48 | 30 | 25 |
| spot | **137** | **25** | **18** | **112** | 29 | 15 |

主要结论：约 80% 的 FN 属于完全未检测到，因此继续扫描 NMS IoU 或只调整置信度阈值无法解决主要问题。下一步需要判断是训练集上也未学会，还是仅在验证集上泛化不足。

## 8. 当前判断

1. 分类别阈值能够减少误检，但没有明显提高综合检测能力。
2. `spot` 是当前绝对错误数量最大的类别，应优先分析。
3. `scratch` 的 Recall 从 0.25 提升到 0.40，说明部分 scratch 预测置信度较低；但验证实例只有 20 个，统计稳定性不足。
4. `splash` 和 `spot` 存在大量完全漏检，是当前 Recall 偏低的主要来源。
5. 约 80% 的 FN 完全没有有效预测，主要矛盾已经从后处理阈值转向模型学习能力、标注质量和数据覆盖。
6. 在训练集/验证集差距尚未确认前，不继续盲目调整学习率、Mosaic 或优化器。
