## 已做内容及其分析

### 1. 训练策略与参数探索

- 完成检测基准训练与结果可视化，确认早停后应以 `best.pt` 而非 `last.pt` 作为比较对象。
- 对比离线 scratch 增强、在线轻增强、几何增强、低 HSV 增强、Mosaic、学习率及 2048 高分辨率输入。
- 已验证结论：
  - 在线增强及轻量 Mosaic 对总体指标有稳定的正向作用；
  - 离线 scratch 粘贴与残差融合未形成稳定收益，可能引入合成分布偏差；
  - 2048 输入有利于细小/细长缺陷的定位，但训练时间和显存开销明显增加；
  - 仅调学习率或更换优化器不能替代数据覆盖与标签质量的改进。

分析：目前在线增强和 Mosaic 的有效性，说明模型需要一定的场景扰动来降低对固定成像条件的依赖；但离线合成没有稳定增益，说明“样本文件数增加”不等于“有效信息增加”。对于 scratch，合成边缘、纹理和真实反光分布不一致时，模型反而可能学习到伪特征。

### 3. 阈值扫描与后处理基线

已在固定验证集完成置信度阈值扫描：

| 统一阈值 | P | R | F1 | TP / FP / FN |
|---:|---:|---:|---:|---|
| 0.05 | 0.248 | 0.742 | 0.371 | 631 / 1918 / 219 |
| 0.15 | 0.397 | 0.594 | 0.476 | 505 / 768 / 345 |
| 0.25 | 0.509 | 0.509 | **0.509** | 433 / 418 / 417 |
| 0.35 | 0.596 | 0.421 | 0.493 | 358 / 243 / 492 |
| 0.50 | 0.679 | 0.304 | 0.420 | 258 / 122 / 592 |

- 当前统一阈值基线：`conf=0.25`，在固定验证集上总体 F1 最优。
- 分类别阈值可以在 precision 与 recall 之间调整取舍，但不能凭空恢复模型没有学到的缺陷。
- 阈值扫描诊断显示：任意类别匹配与同类别匹配的差异很小，说明主要矛盾是漏检/定位不足，而不是大规模类别混淆。

分析：降低阈值能提高召回，但会快速带来大量 FP；提高阈值能提高精度，却牺牲大量 FN。因此后处理的作用是选择业务上的 P/R 平衡点，不能取代模型对难例的识别能力。

### 4. 错误样本导出与人工复核准备

已完成固定验证集 `conf=0.25、IoU=0.50` 的错误导出：

- 漏检 FN：417；误检 FP：418。
- 已输出每类 FN / FP 图像、对应标签、预测标签、`error_cases.csv` 和 `pr_metrics.csv`。
- 错误分析输出目录：
  - `runs_668_error_analysis/baseline_conf025_iou070_errors`
  - `runs_668_error_analysis/baseline_conf025_iou070_errors/error_cases.csv`

人工复核重点：

1. **FN（漏检）**：分别检查 scratch、splash、spot 的缺陷尺度、低对比、反光遮挡、贴近工件边缘、标注漏标或标注过小等情况。
2. **FP（误检）**：检查模型是否将工件边缘、反光、高亮点、纹理或其他类瑕疵识别为目标类。
3. **类别混淆**：重点记录 splash ↔ spot、边缘反光 ↔ chipping 等混淆模式。
4. **标注质量**：发现漏标、错类、边界不一致时，单独记录为“标注问题”，避免误判为模型能力不足。

分析：FN/FP 的人工归因是当前最重要的证据补全步骤。只有区分“模型未学会”“标注不一致”“缺陷本身不可见或模糊”“阈值造成的取舍”，后续训练方案才具有针对性。

### 推荐执行顺序

1. 先完成 FN/FP 人工复核与标签核查；
2. 根据归因结果补充真实样本或修订标签；
3. 固定 2048 高分辨率基线，做少量可解释的增强复验；
4. 最后再进行分类别阈值部署验证和模型结构对比。

说明：将数据量从千级扩至万级只有在新增样本具有**独立性与真实分布覆盖**时才有较大价值。对已有少量样本进行机械复制、过强合成或同源重复，并不能等价于新增真实样本。
