# 项目交接说明（YOLO11 改进模型）

## 一、这是什么
基于 Ultralytics YOLO11 的目标检测项目，核心改进是自定义模块
**C3k2-MutilScaleEdgeInformationEnhance（多尺度边缘信息增强）**。
任务：表面缺陷检测，3 类 —— `splash`（飞溅）、`chipping`（崩边）、`scratch`（划痕）。

## 二、目录结构
```
ultralytics-yolo11/
├── ultralytics/          # 框架源码（已含改进模块，无需 pip 安装官方版）
│   └── cfg/models/11/yolo11-C3k2-MutilScaleEdgeInformationEnhance.yaml  ← 改进模型配置
│   └── nn/extra_modules/block.py   ← 改进模块 C3k2_MutilScaleEdgeInformationEnhance 定义处
├── datasets/             # 完整数据集（train 3320 / val 48 / test 48，BMP 图 + YOLO 标签）
│   └── data.yaml         # 数据集配置（相对路径，已可移植）
├── train.py              # 训练脚本（已指向改进模型）
├── val.py                # 验证/出指标脚本（参数量、FLOPs、mAP 等）
├── util/                 # 数据预处理脚本（格式转换、增强、划分等）
├── yolo11n.pt            # 官方预训练权重（可选加载）
├── pyproject.toml        # 依赖与安装配置
├── 使用说明.md / YOLOV11配置文件.md   # 原作者使用文档与常见问题
└── 师弟必读说明.md        # 本文件
```

## 三、环境准备
本机需要安装 PyTorch（GPU 版）和依赖：
```bash
# 1) 先按你的 CUDA 版本装 PyTorch：https://pytorch.org/get-started/locally/
# 2) 在项目根目录安装本地 ultralytics（开发模式，改代码即时生效）
pip install -e .
```

## 四、训练
```bash
python train.py
```
- 模型：`yolo11-C3k2-MutilScaleEdgeInformationEnhance.yaml`（在 train.py 里已设好）
- 数据：`datasets/data.yaml`
- 关键参数：`imgsz=2048, epochs=150, batch=4`（显存不足就调小 batch / imgsz）
- 结果保存在 `runs/train/exp/`

## 五、验证 / 出论文指标
训练完成后：
```bash
python val.py
```
默认读取 `runs/train/exp/weights/best.pt`，输出参数量、GFLOPs、FPS、各类别 P/R/F1/mAP。

## 六、注意事项
- `train.py` / `val.py` / `data.yaml` 里的路径**已改成相对/自动路径**，整个文件夹拷到别处也能直接跑。
- 若 import 报某些算子（如 DCNv4、mamba 等）缺失，是这些可选模块需要单独编译，**本改进模型用不到**，不影响训练。
- `datasets/rename_map_*.csv` 是图片"原名→新名"的对照表，用于追溯，不影响训练。
